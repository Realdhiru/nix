- **Severity**: Bug / Perf
- **Evidence**: `dotfiles/hypr/scripts/quickshell/music/MusicPopup.qml:499-504, 561-564`:
  ```qml
  NumberAnimation on rotation {
      from: 0; to: 360; duration: 8000
      loops: Animation.Infinite
      running: true
      paused: root.musicData.status !== "Playing"
  }
  SequentialAnimation on x {
      id: titleAnim
      loops: Animation.Infinite
  ```

  `running: root.visible && titleTextMain.implicitWidth > titleClipRect.width`.
- **Risk**: Very low.
